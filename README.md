# Proyecto Vue (firstclass)

Aplicación web construida con **Vue 3** y Vue CLI. Proyecto de aprendizaje / base para aplicaciones frontend.

## Tecnologías

- Vue 3
- Vue CLI
- Babel
- ESLint

## Cómo ejecutarlo

```bash
# Instalar dependencias
npm install

# Desarrollo (hot-reload)
npm run serve

# Build de producción
npm run build

# Linter
npm run lint
```

## Personalización

Consulta la [documentación de configuración de Vue CLI](https://cli.vuejs.org/config/).
